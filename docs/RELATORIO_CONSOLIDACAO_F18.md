## Proteções reforçadas
1. O relatório técnico registra ambiente, DOM, assets, storage e erros.
2. Saves antigos recebem schema versão 3 em memória antes da carga.
3. O service worker não interrompe toda a instalação caso um único asset opcional falhe.
4. Todos os arquivos recebem hash SHA-256 no manifesto final.
