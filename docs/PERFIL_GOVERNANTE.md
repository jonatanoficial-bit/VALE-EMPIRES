# Perfil do Governante

## Estrutura salva
```json
{
  "name": "Nome escolhido",
  "avatar": "governor",
  "nation": "england",
  "createdAt": "ISO-8601"
}
```

## Localização
- perfil independente: `localStorage[valeEmpires.profile]`
- campanha: campo `profile` dentro de `localStorage[valeEmpires.save]`

## IDs de avatar
- `governor`
- `commander`
- `ranger`
- `rider`
- `hero`
- `sovereign`

## IDs de nação
- `england`
- `france`
- `byzantium`
- `mongol`
- `cordoba`
- `norse`
